# KernelSU OTA

Device JSON files for KernelSU-rooted GrapheneOS builds.

| Device | File |
|--------|------|
| Pixel 8 (shiba) | [shiba.json](shiba.json) |

## Usage

In Custota app, set OTA server URL to:

- `https://warpdotsys.github.io/rooted-graphene/ksu` (推荐)
- `https://warpdotsys.github.io/rooted-graphene/kernelsu` (兼容旧链接)
